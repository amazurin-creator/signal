◆ How it works
  • BYOK — your key, your cost. The server holds no API key. Enter your sk-ant-… key once; it stays only in your browser's localStorage. Each request sends it in a custom header; the Worker uses it for that one call and never stores, logs, or echoes it.
  • One LLM call per batch. All reviews are sent in a single API request — never one call per review. Structured output is enforced with tool_choice, so parsing is deterministic and tokens aren't wasted on free-form prose.
  • Normalize first. Input is trimmed, deduplicated, truncated to 400 chars/review, and capped at 200 reviews before the prompt is built. This directly reduces prompt token count.
  • Exact cache via SHA-256. The normalized input is hashed and checked before the key is even read. Identical inputs cost $0 and return instantly with cache_hit: true — no key required.
  • Quote validation in code. Quotes returned by the model are verified to be verbatim substrings of the input. Any hallucinated quote is dropped server-side without a retry call.
  • Demo mode. No key? Load sample shows a bundled pre-computed result — same schema as a live run, clearly labelled. Add a key and click again to run it live.
